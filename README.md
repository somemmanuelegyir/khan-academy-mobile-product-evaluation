Khan Academy — Initial Mobile Product Evaluation

An independent mobile product management portfolio project.

Project Overview

This project evaluates the mobile web experience of "Khan Academy" (https://www.khanacademy.org/) using an Android phone. The evaluation focuses on the learner experience, course continuity, progress visibility, and selected learning features.

The purpose was to understand how the product supports learners and to document observations using a product management perspective.

Evaluation Scope

The evaluation explored:

- Homepage and educational value communication
- Course discovery and navigation
- Lesson presentation and learning flow
- Resume functionality
- Course progress indicators
- Learner dashboard
- Tests and assessments
- Areas requiring further investigation

Key Findings

The evaluation found that the main call to action was visible, course discovery was straightforward, and lesson instructions, practice, feedback, and navigation felt clear during the exploration.

The Resume function returned the learner to the course, while the progress indicator communicated progress through a course. The dashboard displayed profile information, personal courses, badges, and other features.

Some areas, including behavior after lesson completion and personalized recommendations, were not verified and remain open questions.

Methodology and Limitations

This was an exploratory review conducted by one evaluator on an Android phone. It was not a formal usability study and did not include participant interviews, surveys, internal analytics, or quantitative learning-outcome measurements.

Findings represent the evaluator's observations and interpretations, not verified conclusions about all Khan Academy users.
